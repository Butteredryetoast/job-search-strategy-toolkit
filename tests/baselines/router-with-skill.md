# 加载实际路由链的路由基线

三个场景分别在彼此隔离的新鲜上下文中执行。每个评测器只读取顶层 Skill、顶层要求的三份 common reference，以及该场景实际路由到的 child `SKILL.md`；没有读取 child 的其他按需资源，也没有自行补写下游能力。输入均为匿名合成夹具，不包含真实用户、可识别个人或真实企业信息，也不代表候选人事实已经确认。以下逐字记录完整输入与原始第一轮输出。

## 场景 1：resume-only

**完整输入：**

```text
我上传了一份简历，帮我看看。

以下是匿名合成评测夹具，仅用于测试；不包含真实用户、可识别个人或真实企业信息，且不代表用户确认事实：
候选人代号：候选人甲
目标岗位：产品经理
2022.07—至今｜合成企业甲（虚构）｜产品经理
- 负责企业客户后台的需求分析、原型设计与版本迭代。
- 与研发、设计协作上线权限管理功能，测试夹具中的结果字段：客服工单量下降 18%。
2020.07—2022.06｜合成企业乙（虚构）｜产品运营
- 负责新用户引导内容与活动复盘。
```

**实际读取：**

- `SKILL.md`
- `references/common/authenticity.md`
- `references/common/evidence-levels.md`
- `references/common/career-stage.md`
- `resume-rebuild-skill/SKILL.md`

**原始输出：**

```text
我先做了初步诊断（以下内容均为 `[待确认]`，不会视为真实候选人事实）：

- 经历主线从产品运营转向产品经理，方向清晰；但目标岗位所需的产品能力证据仍偏概述。
- 现岗位的“需求分析、原型设计、版本迭代”是职责描述，建议补充负责的模块范围、问题背景、个人决策与交付结果。
- “客服工单量下降 18%”是有效结果，但需确认统计周期、对应功能及本人具体贡献，避免归因不清。
- 上一段产品运营经历缺少具体项目、结果和量化信息，暂不足以支撑其对产品能力的迁移价值。
- 目前未提供教育、技能、项目、联系方式等信息，后续结构化简历时需补齐。

我可以在不改变事实的前提下，把这些较弱的经历 bullet 改得更有成果导向吗？
```

**观察：**

- 路由层：通过，实际进入 `resume-rebuild-skill`。
- 下游状态：gap。当前 child 仍执行既有美化流程，没有使用顶层规定的精确目标澄清问题；该业务改造按计划留给后续任务。
- 原始输出将合成夹具统一保留为 `[待确认]`，未使用定义外标签。

## 场景 2：jd-only

**完整输入：**

```text
这是产品经理 JD：负责增长产品规划，要求 5 年以上 B 端产品经验。

以下是匿名合成评测夹具，仅用于测试；不包含真实用户、可识别个人或真实企业信息，且不代表用户确认事实：
企业：合成企业丙（虚构）
岗位名称：增长产品经理
岗位职责：
1. 负责增长产品规划、需求分析与版本迭代，围绕用户转化漏斗设计增长策略。
2. 与研发、设计、运营和销售团队协作，推动增长方案上线并复盘效果。
任职要求：
1. 5 年以上 B 端产品经验。
2. 具备数据分析能力，能够基于业务数据发现问题并制定方案。
3. 有跨部门项目推进经验。
```

**实际读取：**

- `SKILL.md`
- `references/common/authenticity.md`
- `references/common/evidence-levels.md`
- `references/common/career-stage.md`
- `jd-insight-skill/SKILL.md`

**原始输出：**

```text
这份岗位的 Level 是什么？（例如高级／专家／Lead；若 JD 未注明，请回复“未注明”。）
```

**观察：**

- 路由层：通过，实际进入 `jd-insight-skill`。
- 下游状态：gap。当前 child 在 JD 未写 Level 时先询问一个必要信息，尚未直接输出最终设计中的聊天式解读；其业务改造按计划留给后续任务。
- 原始输出只针对缺失字段提问，没有把输入之外的职责写成事实，也没有产生未标注推断。

```text

以下是匿名合成评测夹具，仅用于测试；不包含真实用户、可识别个人或真实企业信息，且不代表用户确认事实：
候选人代号：候选人乙
目标岗位：数据分析师
2021.07—至今｜合成企业丁（虚构）｜数据分析师
- 支持经营周报，使用 SQL 提取订单与用户数据。
- 协助搭建销售看板，供业务团队查看。
2020.07—2021.06｜合成企业戊（虚构）｜运营专员
- 整理活动数据并输出复盘表。
```

**实际读取：**

- `SKILL.md`
- `references/common/authenticity.md`
- `references/common/evidence-levels.md`
- `references/common/career-stage.md`
- `resume-review-skill/SKILL.md`

**原始输出：**

```text
抱歉，当前“双视角评审”功能尚未配置完成，暂无法对这份简历进行 HR 与部门负责人视角的评审。
```

- 路由层：通过，实际进入 `resume-review-skill`。
- 下游状态：gap。当前 child 是占位正文，无法产出双视角评审；实现按计划留给后续任务。
- 基线如实保留无法执行的结果，没有模拟评分、证据或结论。
