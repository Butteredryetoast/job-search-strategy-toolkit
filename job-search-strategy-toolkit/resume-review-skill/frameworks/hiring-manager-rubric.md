# 部门负责人评审评分标准

## 评分维度与权重

- 专业能力：20
- 业务理解：15
- 项目复杂度：15
- 个人贡献：15
- 结果可信度：15
- Ownership与协作：10
- 即战力与培养成本：10

## 评分区间

- 80–100：强烈推荐面试
- 65–79：面试但需针对性追问
- 50–64：证据薄弱
- 低于50：角色匹配度低

## 重要规则

**性别不参与评分。**

评分零分是有效的，当证据缺失时不得编造证据。

## 评分输出格式

每个维度输出：
- dimension: 维度名称
- score: 得分
- max_score: 满分
- evidence: ["简历原文或JD条款"]
- risk: "明确风险或无"
- confidence: "high、medium或low"
- next_question: "需要面试验证的问题或无"
