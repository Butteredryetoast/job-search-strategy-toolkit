# JD匹配评分

## 权重分配

- 核心职责匹配：30%
- Must-have：30%
- 简历证据强度：20%
- 行业与业务背景：10%
- Nice-to-have：10%

## 评分规则

**先列硬性阻断项，再计算综合分。硬性阻断项不得被综合分掩盖。**

### 证据档位

每条证据使用四档：
- 3：直接、具体、可量化的强证据
- 2：直接但缺少规模或结果
- 1：可迁移的间接证据
- 0：没有证据

### 匹配度区间

- 80–100：强匹配，值得重点投递
- 65–79：可行，但有明确 Gap 需要补充
- 50–64：高风险投递，Gap 较大
- 低于 50：匹配度低，不建议投递

**注意：存在硬性阻断项时，即使综合分高于 65，也应标记为"谨慎投递"或"不建议投递"。**
